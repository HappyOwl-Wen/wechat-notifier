## 准备（PHASE 2/3 用的控制台宿主）

控制台宿主和后台程序不能同时运行：先在托盘菜单里「退出」（或 `WeChatNotifier.exe --exit`），用完控制台宿主后再启动 `WeChatNotifier.exe`。

```powershell
.\scripts\build.ps1
.\src\WeChatNotifier.ConsoleHost\bin\Release\net10.0-windows10.0.19041.0\WeChatNotifier.ConsoleHost.exe
```

`cmd` 里要写 `.\WeChatNotifier.ConsoleHost.exe`。启动时应该看到：

```
[toast] Windows notifications on — they appear as «WeChat Notifier» (Settings → System → Notifications)
[status] attached to WeChat pid=… v4.1.13.65; window=Visible; references=10 cells; …
```

每条检测结果在控制台一行，同时弹出一条 Windows 通知。绿色 = 有内容；黄色 = 只有会话/未读数（托盘），或通用「新消息」。按 Ctrl+C 结束后会打印汇总（含 `notifications: shown=…` 和 `flash→notification` 延迟）。
